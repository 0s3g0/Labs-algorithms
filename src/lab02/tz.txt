Создайте проект консольного приложения с системой контроля версий Git (5 баллов).
Все необходимые данные (согласно своему варианту, если это требуется) вводятся
пользователем с клавиатуры (обязательна проверка корректности ввода, 5 баллов)
либо данные могут заполняться случайным образом, при вводе/выводе данных организовать
информативный диалог с пользователем (5 баллов).  Разработать программу, реализовав в
виде функций (как минимум должны быть функции чтения/записи в файл, а также проверок см. дальше)
для работы с файлами один из вариантов задания в соответствии с таблицей. В заданиях,
где необходимо открыть уже существующие файлы обязательна проверка, что заданный файл
существует и он не пуст, в противном случае вывести сообщение о том, что файл не существует
или он пуст и завершить работу программы (5 баллов). Файлы должны иметь расширение .txt.
Допускается реализация на любом языке программирования.

1. Дан текстовый файл b, вводится целое число K (проверка числа, что оно > 0 и не вещественное,
ввод будет продолжаться до тех пор, пока не будет введено верное значение). Удалить из него последние K строк.
Если файл содержит меньше K строк, сообщить об этом пользователю, завершить программу.

2. Подсчитать количество вхождений заданного пользователем слова в текстовый файл и вывести результат подсчета.
В случае отсутствия в файле заданного пользователем слова вывести об этом сообщение.
