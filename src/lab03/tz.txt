Создайте проект консольного приложения с системой контроля версий Git (5 баллов).
Все необходимые данные вводятся пользователем с клавиатуры
(обязательна проверка корректности ввода, 10 баллов), массивы заполняются случайным образом.
При вводе/выводе данных организовать информативный диалог с пользователем (5 баллов).
Лабораторная работа состоит из двух заданий. Если в задании не указан размер массива,
то массив считается динамическим и его размер пользователь вводит с клавиатуры.
Работа с элементами массива происходит только с помощью указателя, без использования индексации.
При выполнении лабораторной работы:

1.	Определить структуры данных представляющие собой 2 сегмента динамической памяти.

2.	Реализовать функцию размещения в статическом сегменте указателя, и
выделения памяти для хранения значения, на которое ссылается указатель
NewPointer(p, byte) - выделяет память в одном из сегментов и сохраняет информацию
об указателе в статическом сегменте. Сегмент для размещения должен выбираться автоматически.

3.	Реализовать функции чтения и присвоения значений, на которые ссылаются указатели:
WritePointer(p, 5) - записывает значение по адресу, на который ссылается указатель,
ReadPointer(p) -  возвращает это значение по адресу.

4.	Реализовать функцию присвоения значения одного указателя другому
SetPointer(p, b) - копирует значение, на которое ссылается указатель b,
в память, на которую ссылается указатель p.

5.	Реализовать функцию освобождения памяти FreePointer(p).

Примечания

Предусмотреть невозможность выделения памяти в случае нехватки места в сегментах.
При чтении указателя обрабатывать возможность пустого значения (null).
Резервировать динамическую память при выделении памяти для указателя.
При выделении памяти под уже существующий указатель эмулировать процесс утечки памяти
 (создать указатель и выделить для него память; повторно выделить память для этого же
 указателя, не освобождая старую; продемонстрировать, что старая память стала недоступной,
 и это привело к утечке).

 1. Сгенерировать массив А из n элементов, найти сумму элементов,
 больших 2 и меньших 20 и кратных 8, их количество и вывести результаты на экран.

 2. В одномерном массиве, состоящем из n вещественных элементов,
 вычислить количество элементов массива, лежащих в диапазоне от А до В.
